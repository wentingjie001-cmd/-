# 说明书摘要（初稿，正文 ≤ 300 字）

本发明公开了一种背包随动背负系统及背包。背负系统包括背架、左右肩带、腰带、联动座、联动带和锁止组件。联动座固定于背架下部、位于包底贴身侧中央，内设左右间隔的两个滚轮及连通二者的导向通道；联动带穿过导向通道并绕过两滚轮后从联动座两端的出带口伸出，分别连接左右肩带下端。锁止组件可在释放位置与锁止位置间切换：释放时联动带可往复移动，左右肩带此升彼降地联动；锁止时联动带被压紧固定。还可设置回中弹性件、行程限位块、Y型背架、上下两区独立张紧的悬浮网面与腰垫，以及与联动座同轴的腰带枢转盘。本发明联动阻力小，可在随动与固定两种背负状态间快速切换，兼顾行走舒适与复杂地形下的稳定。
