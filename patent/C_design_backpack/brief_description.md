# 外观设计简要说明（初稿）

1. **本外观设计产品的名称：** 背包。
2. **本外观设计产品的用途：** 用于户外徒步、登山时背负携带物品。
3. **本外观设计产品的设计要点：** 在于产品的形状，包括卷口式包体整体轮廓、正面倒梯形前袋及其上方汇于中心的 V 形压缩绳、两侧上收下放的侧袋，以及背部的背负系统造型。
4. **最能表明设计要点的图片或照片：** 立体图。
5. **其他说明：** 肩带、腰带为软质材料，图示为背负状态下的展开形态。

视图文件（`cad/out/design/01_backpack_whole/`）：主视图 `front`、后视图 `rear`、左视图 `left`、右视图 `right`、俯视图 `top`、仰视图 `bottom`、立体图 `iso_front`。

> 若定稿样包与 CAD 线条图差异较大，建议改用样包照片（单色背景，视图方向与上列一致）。如果产品左右对称，可与代理师商量省略右视图，并在简要说明中写明"右视图与左视图对称，省略右视图"。
