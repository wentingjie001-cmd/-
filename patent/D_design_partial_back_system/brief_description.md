# 外观设计简要说明（局部外观设计，初稿）

1. **本外观设计产品的名称：** 背包的背负系统。
2. **本外观设计产品的用途：** 背包用于户外徒步、登山时背负携带物品；要求保护的背负系统部分用于将背包贴合并支承于使用者背部。
3. **本外观设计产品的设计要点：** 在于要求保护部分的形状，包括 Y 型背架、沙漏形上区网面、左右分体并留有竖向通风槽的腰垫、两端上翘呈弧形的联动座及其扳手，以及自联动座两端斜向上伸出的联动带。
4. **最能表明设计要点的图片或照片：** 立体图（背面）。
5. **其他说明：** 本外观设计为局部外观设计，视图中 **实线所示部分为要求保护的部分**，虚线所示部分为不要求保护的部分。

视图文件（`cad/out/design/02_backpack_partial_back_system/`）：主视图 `front`、后视图 `rear`、左视图 `left`、右视图 `right`、俯视图 `top`、仰视图 `bottom`、立体图（背面）`iso_rear`。

> 局部外观设计的视图应与整体产品一致，仅以线型区分保护范围。代理师可能建议删去要求保护部分完全被遮挡的视图（如主视图），并在简要说明中写明省略理由。
