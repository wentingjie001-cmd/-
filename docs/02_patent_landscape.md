**结论：**

1. 检索到的 Aarn 专利族 **没有中国（CN）同族**。专利有地域性，这些专利在中国不产生保护，在中国生产销售不构成侵权（仍需正式 FTO 确认，尤其要查是否有第三方在中国申请了相似结构）。
2. 它们的核心机构（U-Flow 联动、S 形/内凹背架、前置平衡袋）都已 **公开 20 年左右**，属于全球现有技术。**我们不能把这些原理本身拿去申请中国专利**：会因缺乏新颖性/创造性被驳回，授权后也容易被宣告无效。照搬他人公开技术去申请，还可能被认定为非正常专利申请。
3. 所以专利必须建立在 **我们自己的改进** 上（见 03 文档的 5 个创新点），并把 Aarn 的公开文献写进说明书"背景技术"，主动说明区别。

## 3. 规避与风险清单

| 风险 | 说明 | 措施 |
|---|---|---|
| 新颖性 / 创造性不足 | 联动肩带、悬浮网、枢转腰带单独看都是现有技术。**"滚轮联动 + 可切换锁止"这个组合也已被 CN2800884Y（2005）公开，见第 4 节** | 独立权利要求不能再只靠"滚轮联动 + 可切换锁止"。要把腰带同轴枢转、背架下立杆插接、回中、限位中的一项或几项并入独立权利要求，具体由代理师检索后决定 |
| 外观与 Aarn 近似 | 整体造型、配色、前部抽绳样式过于接近会削弱外观专利，也可能引发仿冒/不正当竞争争议 | 我们的外观与 Aarn 明显区分（卷口、V 形压缩绳、倒梯形前袋、Y 型背部），不使用其绿/灰配色组合 |
| 商标 | "Aarn"、"U-Flow"、"Balance Pockets"、"Pace Magic"、"Auto-Mould" 是对方品牌用语 | 产品、宣传与专利文本中都不使用这些名称，统一用中性技术术语（"随动""联动座""双区张紧"） |
| 提前公开 | 申请日前在电商、众筹、展会、社交媒体发布图片或样品，会破坏自己的新颖性 | **先申请，后公开**。打样厂、外包设计签保密协议（NDA） |
| 第三方中国专利 | 可能有国内企业申请过相似结构 | 申请前做 FTO 检索，尤其是联动座、锁止、腰带枢转三项 |

## 4. 2026-11-12 补充检索：肩带联动的现有技术比原先认为的多

做品牌结构调研（[06](06_brand_suspension_survey.md)）时，又查到一批肩带联动、腰带活动连接的专利。完整表格、链接和法律状态在 06 的第 6、7 节，这里只写对我们申请有影响的部分。法律状态取自 Google Patents，没有在 CNIPA 复核。

### 4.1 对独立权利要求影响最大的一件

**[CN2800884Y](https://patents.google.com/patent/CN2800884Y/zh)"互动式平衡装置"**（叶啓明，申请日 2005-06-30，实用新型；同族 US7946460B2、EP1902646A1、JP4783828B2）。已因未缴年费终止（终止日 2012-06-30），现在是现有技术。它公开了：

- 背包下部的挡板夹层里装有至少一个滚轮和左右两个固定轮；
- 一根滑动带绕过这些轮子，两端接左右肩带，一侧肩带上提时另一侧下放；
- 滚轮之间设有一个开关控制键，可以锁紧或放开滑动带；
- 滚轮可以带弹簧安装。

这和我们权利要求 1 的特征（座内两个滚轮 + 导向通道 + 联动带接两肩带 + 可切换锁止）基本重合。**按现在的写法，权利要求 1 很可能没有新颖性，至少没有创造性。**

同一发明人更早的 [CN2659216Y](https://patents.google.com/patent/CN2659216Y/zh)（2003）公开了包底通道里的连接带接两肩带，并提到可以用滑轮实现。更早的还有 US6070776A（1997，包底低摩擦通道内的连续带）和 FR2819700A1（Salomon，2001）。

### 4.2 我们还剩下什么可以保护

下面几项在本次检索里没有找到直接公开的文献。检索不完整，只能当作线索：

| 特征 | 现在所在的权利要求 | 说明 |
|---|---|---|
| 腰带通过枢转盘转动连接在同一个联动座上 | 13 | 最接近的是 Hiam US8172117B2（滑轮绳索肩部悬挂 + 铰接髋杆），但它是连杆机构，不是一个集成座 |
| Y 型背架的单根下立杆插入联动座的插座，可小幅扭转 | 9 | 把背架载荷直接传到联动座和腰带 |
| 回中弹性件 + 中位件 | 4 | CN2800884Y 有带弹簧的滚轮，作用不同，需要代理师比对 |
| 可调限位块限定单侧行程 | 5、6 | 评测指出同类产品有左右晃的问题，限位有实际效果，有利于说明创造性 |
| 凸轮 + 扳手，可用拉索在腰带上操作 | 2、3 | CN2800884Y 的锁止是"开关控制键"，结构不同 |

**建议的改法（由代理师定）：** 把"腰带经枢转盘与联动座转动连接"和"背架下立杆插入联动座"并入独立权利要求，保护的重点从"滚轮 + 锁止"改为"肩部联动、锁止、腰带枢转、背架插接集成在一个刚性座上"。说明书的背景技术要写入 CN2800884Y 和 CN2659216Y，并逐项说明区别。实用新型不做实质审查，按原样也可能授权，但授权后很容易被宣告无效，不建议原样提交。

### 4.3 自由实施

- **中国：** 本次没有查到仍然有效、且覆盖"滚轮联动 + 锁止"基本机构的中国专利。CN2800884Y 和 CN2659216Y 都已终止。仍有效、机构不同但需要代理师看一眼的有：Coxa Carry 的 CN106923401B 和 CN104640477B（胸前汇合的连接体、可沿背带移动的连接件），Moncreiff 的 CN106535705B（胸带环和连杆、腰带支撑杆），凯乐石的 CN222639968U（带凹槽的成型背板），Osprey 的 CN114980777B（3D 打印点阵腰垫）。
- **美国、欧洲：** 如果以后出口，下面这些在美国仍有效，没有查到中国同族，出口前必须请律师比对权利要求：Black Diamond US9254030B2（肩带经耦合件在套管内滑动联动，到 2033 年）和 US8714424B2（球铰腰带）、Hiam US8172117B2、Frenchie US12089711B2、Arc'teryx US10004320B2、Gregory US10806238B2。Mammut 的 DE102017219211B4 在德国有效。
