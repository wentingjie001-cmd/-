> 本文是 **初步检索**（Google Patents 按发明人/申请人与关键词检索，2026-11-09）。正式申请前，必须由专利代理师在 CNIPA 专利检索及分析系统、incoPat、智慧芽等数据库做 **新颖性检索 + 自由实施（FTO）检索**。

**结论：**

1. 检索到的 Aarn 专利族 **没有中国（CN）同族**。专利有地域性，这些专利在中国不产生保护，在中国生产销售不构成侵权（仍需正式 FTO 确认，尤其要查是否有第三方在中国申请了相似结构）。
2. 它们的核心机构（U-Flow 联动、S 形/内凹背架、前置平衡袋）都已 **公开 20 年左右**，属于全球现有技术。**我们不能把这些原理本身拿去申请中国专利**：会因缺乏新颖性/创造性被驳回，授权后也容易被宣告无效。照搬他人公开技术去申请，还可能被认定为非正常专利申请。
3. 所以专利必须建立在 **我们自己的改进** 上（见 03 文档的 5 个创新点），并把 Aarn 的公开文献写进说明书"背景技术"，主动说明区别。

## 3. 规避与风险清单

| 风险 | 说明 | 措施 |
|---|---|---|
| 新颖性 / 创造性不足 | 联动肩带、悬浮网、枢转腰带单独看都是现有技术 | 独立权利要求以 **"滚轮联动 + 可切换锁止"的组合** 为核心，回中、限位、Y 架、双区张紧、同轴枢转写成从属权利要求，形成多层防线 |
| 外观与 Aarn 近似 | 整体造型、配色、前部抽绳样式过于接近会削弱外观专利，也可能引发仿冒/不正当竞争争议 | 我们的外观与 Aarn 明显区分（卷口、V 形压缩绳、倒梯形前袋、Y 型背部），不使用其绿/灰配色组合 |
| 商标 | "Aarn"、"U-Flow"、"Balance Pockets"、"Pace Magic"、"Auto-Mould" 是对方品牌用语 | 产品、宣传与专利文本中都不使用这些名称，统一用中性技术术语（"随动""联动座""双区张紧"） |
| 提前公开 | 申请日前在电商、众筹、展会、社交媒体发布图片或样品，会破坏自己的新颖性 | **先申请，后公开**。打样厂、外包设计签保密协议（NDA） |
| 第三方中国专利 | 可能有国内企业申请过相似结构 | 申请前做 FTO 检索，尤其是联动座、锁止、腰带枢转三项 |
